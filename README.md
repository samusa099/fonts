## 📌 Overview

A compact collection of legacy Windows `.FON` bitmap and system font resources preserved for compatibility, testing, and archival reference.

The repository is organised as a self-contained asset collection that can be downloaded and reviewed without a build process.

---

## ✨ Key Features

- ✅ Classic Courier, Roman, Script, Serif, and Small font resources
- ✅ VGA system and fixed-width font files
- ✅ Code-page 850 compatible font assets
- ✅ Direct-download binary files with no build process
- ✅ Useful for legacy Windows and compatibility testing

---

## 🛠️ Resource Types

| Resource | Purpose |
|---|---|
| **Windows Fonts** | Legacy Windows font compatibility |
| **FON** | Binary font resource format |
| **Bitmap Fonts** | Raster-based legacy font rendering |

## 📥 Using the Font Files

1. Download the required `.FON` file from the repository.
2. Keep an untouched backup of the original binary.
3. Test it inside a compatible legacy Windows environment or virtual machine.
4. Confirm the font's license and redistribution rights before packaging it with another project.

> Modern browsers and operating systems may not support `.FON` resources directly.

---

## 🎯 Collection Purpose

- Preserve legacy Windows bitmap font resources
- Support compatibility and migration testing
- Provide reference assets for virtual machines and archival workflows
- Document the contents so each binary file is easy to identify

## ⚠️ Project Notes

These are legacy binary font resources. Install or test them only in a compatible, isolated environment and verify licensing before redistribution.
